# HiperCraft_front
✨ Hipercraft Texture Pack
Seja bem-vindo ao Hipercraft, um pacote de texturas criado por uma equipe de 4 pessoas com a missão de transformar sua experiência no Minecraft 1.19.4 utilizando o OptiFine! Nosso objetivo é revitalizar as texturas de blocos e mods, infundindo mais vida e detalhe ao seu mundo de jogo.
📖 Sobre o Projeto
O Hipercraft é um pacote de recursos (resource pack) focado em aprimoramento visual. Não se trata de uma mudança radical, mas sim de um polimento cuidadoso, elevando a qualidade e a vivacidade das texturas existentes no jogo base e em mods populares. Buscamos um equilíbrio entre o estilo clássico do Minecraft e um visual mais detalhado e imersivo.
🎨 Demonstração
💡 Funcionalidades
 * Texturas de Blocos Aprimoradas: Revisão de texturas de blocos vanilla para maior profundidade e detalhe, mantendo a fidelidade ao estilo Minecraft.
 * Melhoria em Texturas de Mods: Foco inicial em mods populares (especificar quais, se aplicável, ex: JEI, Waystones, etc.) para garantir consistência visual em todo o mundo.
 * Suporte OptiFine: Utilização de recursos avançados do OptiFine, como:
   * Texturas Conectadas (CTM): Para uma transição suave entre blocos do mesmo tipo (vidro, estantes, etc.).
   * Mapeamento Personalizado do Céu/Água: Para ambientes mais atmosféricos.
   * Iluminação e Shaders Aprimorados: Otimização para funcionar bem com shaders populares.
🛠️ Tecnologias Utilizadas
O Hipercraft é primariamente desenvolvido utilizando ferramentas de edição gráfica, sem a necessidade de tecnologias complexas de programação.
 * BlocBlench: Onde criamos os mobs.
 * Canva: Logo-marca
✅ Pré-requisitos
Para utilizar o pacote de texturas Hipercraft, você precisará de:
 * Minecraft Java Edition (Versão 1.19.4).
 * OptiFine (Versão compatível com 1.19.4) instalado.
⬇️ Instalação
 * Baixe o arquivo ZIP do pacote de texturas Hipercraft (Link de download).
 * Inicie o Minecraft com a versão 1.19.4 + OptiFine.
 * Vá para Opções... -> Pacotes de Recursos...
 * Clique em Abrir Pasta de Pacotes de Recursos.
 * Arraste o arquivo ZIP baixado para essa pasta. Não descompacte o arquivo!
 * Retorne ao Minecraft, e o pacote Hipercraft aparecerá na lista de Pacotes Disponíveis.
 * Clique na seta do Hipercraft para movê-lo para a lista de Pacotes Selecionados.
 * Clique em Concluído. O jogo irá recarregar as texturas.
⚙️ Como Usar
Uma vez instalado e ativado, o pacote Hipercraft substitui automaticamente as texturas padrão e as de mods que foram aprimoradas.
 * Verificação de Mods: Se você estiver usando mods, certifique-se de que eles estão na lista de mods suportados pelo Hipercraft.
 * Configurações do OptiFine: Para aproveitar todas as funcionalidades (CTM, céus personalizados), certifique-se de que as opções gráficas do OptiFine como Texturas Conectadas, Objetos Personalizados e Céu Personalizado estejam ativadas.
